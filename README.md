# Electricity Bill Calculator

## 1. Project Title

Electricity Bill Calculator

## 2. Problem Statement

Calculating electricity bills manually can be time-consuming and may lead to calculation errors.

This project provides a Python-based application that calculates an electricity bill based on the number of units consumed. It also includes fixed charges and a late payment fee.

## 3. Objective

The main objective of this project is to develop a simple Python application that can calculate electricity bills automatically using a slab-based pricing system.

The project also demonstrates basic Python programming concepts such as functions, conditional statements, loops, input validation, and exception handling.

## 4. Features

- Customer name and meter number input
- Electricity units input
- Slab-based electricity charge calculation
- Fixed charge calculation
- Late payment fee
- Input validation
- Exception handling
- Bill breakdown
- Total bill calculation

## 5. Technologies Used

- Python
- VS Code

## 6. Installation / Setup

1. Install Python on the computer.
2. Install Visual Studio Code.
3. Open the project folder in VS Code.
4. Make sure Python is properly configured.
5. Open the `electricity_bill.py` file.

## 7. How to Run

Open the VS Code terminal and run:

    python electricity_bill.py

Then enter the requested customer details, meter number, electricity units, and late payment status.

## 9. Testing

The application is tested using different inputs including:

- Normal electricity consumption
- Slab boundary values
- Higher electricity consumption
- Negative units
- Invalid text input
- Invalid late payment input

## 10. Limitations

- The project uses example/configurable electricity rates.
- It is a command-line application.
- It does not connect to a real electricity provider.
- It does not process real payments.
